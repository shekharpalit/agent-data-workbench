Document the standard FastAPI/Uvicorn server lifecycle: the custom server wrapper and socket/browser-readiness code have been removed. FastAPI/Pydantic parses request bodies; there is no workbench 2 MB body cap. Response headers remain application policy. FastAPI BackgroundTasks runs model jobs after responses; the job registry only reserves capacity and records status. Uvicorn graceful shutdown waits for active response background tasks by default; pause long native research explicitly before stopping, and distinguish external Docker stop deadlines from analysis limits. Update old exact-Host-port/same-origin-POST/body-cap claims and the removed browser-opening commands.
